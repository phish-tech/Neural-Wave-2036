- Figure generation scripts (Python/matplotlib) and `.mat` source data — pending a cleanup pass (several scripts depend on local `part_1.mat` and hardcoded paths) for a later release.
- Commercial font files — only font names are referenced.
- Third-party stock images, AI-generated images, and unverified `.zip` materials — excluded pending rights confirmation (see [`ASSET_LICENSES.md`](../visuals/ASSET_LICENSES.md)).
- Process files, drafts, working documents, and reviewer correspondence.
