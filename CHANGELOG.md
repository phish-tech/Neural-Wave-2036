this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-12 — Public Archive Release

### Added

- `README.md` with archive-first presentation and four entry points (Paper / Manual / Archive / Citation).
- `CITATION.cff` (v1.2.0) for the repository-level citation.
- Dual license: `LICENSE-CODE` (MIT) and `LICENSE-CONTENT` (CC BY 4.0).
- `paper/` — author preprint PDF (`neural_wave_quick_escape_manual_2036_preprint.pdf`) and `citation.bib`.
- `manual/` — the Quick Escape Manual artifact PDF (`Neural-Wave_Quick_Escape_Manual_2036.pdf`).
- `archive/` — worldbuilding documents: timeline, glossary, empathic-AIoT setting, threat model, scenario cards, design rationale.
- `visuals/` — five selected final figures, cover, and `ASSET_LICENSES.md` asset audit.
- `release/v1.0_notes.md` — what is included / not included / how to cite.

### Not included (by design)

- Publisher-formatted PDF (author rights pending publication).
- Commercial fonts; figure scripts (kept for a later, audited release).
- Process files, drafts, and working materials.
